Pokémon card placeholder generator

This tool generates a grid of Pokémon data, including the national Pokédex number; Pokémon sprite; and optionally some other stuff, designed for printing out to use as placeholders in a card binder.

The printable stylesheet for this enforces a 3-column layout, which results in a 3x3 grid of cards per sheet of portrait A4 paper. If you select the "US Letter" paper type, each card is made a little bit smaller to make a 3x3 grid fit there too, so you're not using as much paper. We don't have any US Letter paper, because we live in a sane country, but it looks okay in a print preview.

For the best results:

  • make sure your print scale is set to 100% (ie. not "scale to page width")
  • turn on the "print backgrounds" option in your browser's print dialog
For A4 prints, in addition to the above:
  • set your page margins to 10mm (roughly 0.39")
